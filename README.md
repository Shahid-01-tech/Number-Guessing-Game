# 🎯 Number Guessing Game

A simple and interactive **Number Guessing Game** built using **HTML, CSS, and JavaScript**.

The computer randomly selects a number between **1 and 100**, and the player tries to guess it. The game provides feedback after every valid guess and keeps track of the number of attempts.

## 🚀 Features

* 🎯 Random number generation between 1 and 100
* ⬆️ Shows **Too High** when the guess is greater than the secret number
* ⬇️ Shows **Too Low** when the guess is smaller than the secret number
* 🎉 Displays a success message when the correct number is guessed
* 🔢 Tracks the number of attempts
* 🚫 Disables the Guess button after winning
* 🔄 Restart button to start a new game
* 🧹 Clears the input and resets the game state
* 📱 Responsive and clean user interface

## 🎮 How to Play

1. Enter a number between **1 and 100**.
2. Click the **Guess** button.
3. The game will tell you whether your guess is:

   * Too High
   * Too Low
   * Correct
4. Keep guessing until you find the number.
5. Click **Restart Game** to start again with a new number.
